## Random Password Generator

A simple Python project that generates random and complex passwords based on the length specified by the user.

## Features

 Allows users to choose their desired password length.
 Generates passwords using letters, numbers, and special characters.
 Uses Python's built-in random and string modules.

## Technologies Used

 Python
 random module
 string module

## How to Run

1. Make sure Python is installed on your computer.
2. Clone or download this repository.
3. Run the Python file:

   bash
   python Task3.py
   
4. Enter your desired password length when prompted.

## Example

text
Enter password length: 12
Your random password is: G7@kP2!xQ9#m
