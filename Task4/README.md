# General Knowledge Quiz

A simple interactive General Knowledge Quiz built with Python as Project 4 during my Python Programming Internship at Decode Labs.

# Project Description

The program asks the user three general knowledge questions, checks their answers, keeps track of their score, and displays the final result at the end.

# Features

* Asks 3 quiz questions
* Accepts and validates user input
* Tracks the user's score
* Provides feedback for each answer
* Displays the final score

# Python Concepts Used

* Variables
* `input()` and `print()`
* `if`, `elif`, and `else`
* Lists
* String methods (`strip()` and `lower()`)
* State management
* Basic decision-making logic

## How to Run

Make sure Python is installed, then run:

```bash
python Task4.py
```

Follow the prompts to answer the questions and see your final score.
